# text-to-voice
Un día cualquiera despiertas, intentas articular palabras con la boca, pero no sale sonido (No puedes hablar). Aquí está **text-to-voice** habla por ti. --- A day may come when you wake up, try to articulate words with your mouth, but no sound comes out (You cannot speak). Here is **text-to-voice**, speak for you.
# text-to-voice

## Cómo usar la app

1. Abre el enlace del proyecto en tu navegador (GitHub Pages).  
2. En el cuadro de texto escribe lo que quieras decir.  
   - Placeholder: *Escribe aquí... / Type here..*  
3. Usa los botones o teclas rápidas:  
   - **Hablar** → Lee en voz alta el texto escrito.  
   - **Borrar** → Cancela la voz y limpia el cuadro de texto.  
   - **Enter** → Atajo para hablar.  
   - **Delete** → Atajo para borrar.  
4. El sistema usará la voz por defecto de tu dispositivo.  
   - Cada usuario escucha en el idioma que ya trae su sistema.

## How to use the app

1. Open the project link in your browser (GitHub Pages).  
2. In the text box, type what you want to say.  
   - Placeholder: *Escribe aquí... / Type here..*  
3. Use the buttons or keyboard shortcuts:  
   - **Talk** → Speaks aloud the text you typed.  
   - **Erase** → Cancels speech and clears the text box.  
   - **Enter** → Shortcut to speak.  
   - **Delete** → Shortcut to erase.  
4. The system will use your device’s default voice.  
   - Each user hears in the language their system already provides.
